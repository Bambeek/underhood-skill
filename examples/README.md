# Examples

Complete mods from the universal-modder project (MIT, see the root LICENSE), kept as working reference
code: Terraria (tModLoader), Age of Empires II DE civilization, Cities: Skylines dashboard, Mindustry,
Minecraft x GTA V and Minecraft x Outer Wilds passthroughs, an Outer Wilds portal gun, Shadow of War
offline mode, and a GMod-style sandbox.

- `um` in these READMEs is the same CLI as `uh` here.
- Their art was generated with a paid service. The generated images and models, and the scripts that
  called that service, are not included. Regenerate locally with `underhood-art` (ComfyUI); the
  READMEs still show the prompts and the pipeline.
- Source only: no game files. Each mod builds against your own install.
